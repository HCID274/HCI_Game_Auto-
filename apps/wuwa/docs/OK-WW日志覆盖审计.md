# OK-WW 日志覆盖审计

## 审计边界

- 安装版本：OK-WW `v3.5.18`。
- 源码位置：本机安装目录中的 `src/task`，不修改上游源码。
- 可用历史日志：`2026-07-26` 至 `2026-07-27`；本机没有更早的 OK-WW 日志，
  因而不能虚构 30 天样本。
- 接入原则：源码支持且历史日志真实出现，并存在稳定的成功或异常边界，才进入
  日报解析器。

## 主流程覆盖矩阵

| OK-WW 功能 | 源码支持 | 历史出现 | 当前处理 |
| --- | --- | --- | --- |
| 无音区 | 是 | 是 | 统计成功领取场次；排除未领宝箱重试；每场按源码固定 60 结晶波片 |
| 凝素领域 | 是 | 否 | 暂不接入，等待真实日志样本 |
| 模拟领域 | 是 | 否 | 暂不接入，等待真实日志样本 |
| 每日活跃度奖励 | 是 | 是 | 至少 100 点时确认领取；否则只报告执行领取操作，最终点数不确认 |
| 先约电台 | 是 | 是 | 仅进入有效领取分支时报告“已执行奖励领取操作” |
| 梦魇巢穴日常声骸 | 是 | 是 | 统计实际吸收；不可达目标进入异常记录 |
| 幻梦游园 | 是 | 是 | 仅本轮运行并出现完成标记时报告；“此前已达 6000”不算本轮完成 |
| 声骸合成 | 是 | 否 | 暂不接入，等待真实日志样本 |
| 讨伐强敌 | 是 | 是 | 保留 GUI 一基编号并统计战斗次数；Boss 名称仅由用户 Markdown 补充 |
| 讨伐后的声骸吸收 | 是 | 是 | 只统计 `FarmEchoTask` 的成功吸收标记，避免混入梦魇巢穴 |

## 已验证的关键边界

1. `current stamina: -36` 是 OK-WW 内部的剩余消耗预算，不是游戏最终体力，
   不能与初始体力相减。无音区消耗改由成功领奖场次计算。
2. `claim daily reward via  coordinate` 只证明脚本点击了固定坐标，不单独证明
   奖励存在或活跃度已满。
3. `farm echo walk find true` 属于梦魇巢穴，而
   `farm echo walk_find_echo True` 属于讨伐强敌；必须带任务类前缀解析。
4. `Garden current: [6000...]` 和 `weekly garden already completed` 是既有状态，
   不能算本轮完成周常。
5. `Daily Task Completed` 是整个日常编排结束边界；子任务页面或点击完成不能替代
   业务事实标记。

## 后续扩展方式

当凝素领域、模拟领域或声骸合成首次真实运行后，保存该次
`runtime/runs/<run_id>/ok-current-run.log`，同时补充成功、跳过和失败样本测试，
再更新本表。不得只根据源码中的任务名直接生成完成事实。
