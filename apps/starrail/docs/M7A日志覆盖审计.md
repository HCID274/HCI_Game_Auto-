# M7A 日志覆盖审计

## 审计边界

- M7A 源码：`moesnow/March7thAssistant` 标签 `v2026.6.8`，提交
  `b43effef32afc2c32e090c13cb04fdd2f5227551`。
- 真实日志：本机 `2026-06-28` 至 `2026-07-27` 共30份日志。
- 接入原则：源码声明支持且近30天真实日志实际出现的业务事实必须解析；源码支持但
  历史从未出现的任务不猜测日志结果。只有明确成功标记可报告领取或完成，章节标题
  “奖励完成”只代表流程返回。

## 覆盖矩阵

| 能力 | 源码支持 | 30天日志 | 解析策略 |
|---|---|---|---|
| 每日实训任务与500/500 | 是 | 有 | 通用任务名、补做结果、分数和最终状态 |
| 体力计划 | 是 | 有 | 副本、次数、剩余计划、明确清零、保留原因 |
| 默认清体力 | 是 | 有（3天） | 独立 `default` 来源，不继承上一条计划 |
| 异器盈界 | 是 | 有（3天） | 活动次数、实际执行数、活动剩余、同名持久计划 |
| 位面分裂 | 是 | 有（1天） | 活动次数、实际执行数、活动剩余、同名持久计划 |
| 花藏繁生 | 是 | 无 | 暂不新增推测性结果；通用活动协议已预留 |
| 300%双倍活动变体 | 是 | 无 | 暂不接入名称，待真实日志出现后取证 |
| 巡星之礼 | 是 | 有（6天） | 仅“领取…奖励完成”进入日报 |
| 巡光之礼、庆典祝礼 | 是 | 无 | 暂不新增推测性结果 |

| 支援、无名勋礼、成就、短信 | 是 | 无稳定正向日志 | 不用章节结束标题伪造领取成功 |
| 资产管理（月度合成/余烬兑换/光锥叠加） | 是 | 无 | 暂不接入 |

## 防回归要求

- 新的计划、活动和默认清体力必须按结构段落隔离状态，禁止跨段复用 active task。
- 体力计划的“剩余N次”和“已完成”分别映射为持久计划 `N` 与 `0`。
- 差分宇宙与兑换码等 `other_tasks` 是确定性事实；DeepSeek遗漏任务、状态或任一数字
  时必须退回确定性摘要。
- 历史回放不得发送飞书，除非调用方显式指定真实发送。
