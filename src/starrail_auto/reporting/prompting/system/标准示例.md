# 星铁日报标准示例

以下示例定义期望的信息层级和措辞。实际输出仍然只返回 JSON，不要输出标题、解释或 Markdown 代码块。

## 示例一：每日实训与培养任务均成功

### 输入摘要

- 最终状态：成功
- 每日实训：500/500
- 本轮补做：派遣委托、万能合成机
- 培养上下文：`鎏金追忆` 对应 Archer 遗器，`魔占之径` 对应 Archer 行迹材料
- 体力任务：饰品提取·鎏金追忆，1轮，每轮领取6次副本奖励，剩余计划25次
- 后续计划：侵蚀隧洞·魔占之径因开拓力不足未执行

### 正确输出

```json
{
  "daily": "1. 为Archer：饰品提取·鎏金追忆 6次，剩余计划25次\n2. 派遣委托\n3. 万能合成机\n4. 每日实训完成 500/500",
  "routine_tasks": [
    "领取每日实训奖励",
    "领取委托奖励",
    "领取无名勋礼奖励"
  ],
  "other_tasks": [
    "侵蚀隧洞·魔占之径（Archer 行迹材料）：未执行（开拓力不足，保留该计划）"
  ],
  "current_task": "",
  "issues": [],
  "training_todos": [
    "Archer：遗器",
    "Archer：行迹材料"
  ]
}
```

## 示例二：每日实训明确失败

### 输入摘要

- 最终状态：失败
- 每日实训：400/500
- 未完成节点：使用支援角色并获得战斗胜利1次
- 最终失败阶段：截图失败，没有找到游戏窗口
- 重试次数：3

### 正确输出

```json
{
  "daily": "1. 未完成：使用支援角色并获得战斗胜利1次\n2. 每日实训未达成 400/500",
  "routine_tasks": [],
  "other_tasks": [],
  "current_task": "失败时停在：每日实训界面识别",
  "issues": [
    "最终失败：截图失败，没有找到游戏窗口；已重试3次"
  ],
  "training_todos": [
    "远坂凛：行迹材料",
    "远坂凛：遗器"
  ]
}
```

## 示例三：每日实训完成，但后续任务超时

### 输入摘要

- 最终状态：失败
- 每日实训：500/500，已经完成
- 后续任务：差分宇宙
- 最后进度：正在进入首领战
- 最终失败阶段：旧版30分钟硬超时

### 正确输出

```json
{
  "daily": "1. 每日实训完成 500/500",
  "routine_tasks": [],
  "other_tasks": [],
  "current_task": "失败时停在：差分宇宙进入首领战",
  "issues": [
    "最终失败：差分宇宙仍在运行，但触发旧版30分钟硬超时"
  ],
  "training_todos": []
}
```

## 示例四：截止汇报时仍在正常运行

### 输入摘要

- 最终状态：仍在进行
- 每日实训：500/500，已经完成
- 当前任务：差分宇宙第三位面首领
- 日志仍持续更新，没有重复失败

### 正确输出

```json
{
  "daily": "1. 每日实训完成 500/500",
  "routine_tasks": [],
  "other_tasks": [],
  "current_task": "仍在进行：差分宇宙第三位面首领；日志持续更新",
  "issues": [],
  "training_todos": []
}
```
